# FarmFeed — Livestock Feed Optimisation App

A Flutter/Flask mobile app helping Zimbabwean livestock farmers optimise feed costs and predict animal performance using machine learning. Dissertation project.

## Overview
Livestock farmers often lack data-driven tools to balance feed costs against animal performance outcomes. FarmFeed brings ML-based predictions to a mobile app, giving farmers accessible, practical guidance for feed decisions without needing technical expertise.

## Features
- Feed cost optimisation recommendations
- Animal performance prediction based on feed inputs
- Mobile-first interface built for farmer accessibility
- ML models integrated directly into the app pipeline

## Tech Stack
- **Frontend:** Flutter (Dart)
- **Backend:** Python, Flask (REST API)
- **ML Models:** Random Forest, XGBoost
- **Other tools:** Git

## How It Works
Farmers input livestock and feed data through the Flutter app. This is sent via a Flask REST API to the backend, where trained Random Forest and XGBoost models generate feed cost optimisation suggestions and predict expected animal performance. Results are returned to the app in a farmer-friendly format.

## Results
Demonstrates full-stack ML deployment — from mobile interface to trained model to real-time prediction — applicable beyond agriculture to mHealth and other resource-constrained deployment contexts.
